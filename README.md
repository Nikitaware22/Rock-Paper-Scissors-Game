# ✊✋✌️ Rock Paper Scissors Game

A simple, interactive, and responsive **Rock Paper Scissors** game built using **HTML, CSS, and JavaScript**. Play against the computer, test your luck, and track your score through a clean and user-friendly interface.

## 🚀 Live Demo

🎮 **Play the game here:**
https://nikitaware22.github.io/Rock-Paper-Scissors-Game/

## 📂 Repository

🔗 **GitHub Repository:**
https://github.com/Nikitaware22/Rock-Paper-Scissors-Game.git

---

## 📌 Features

* 🎮 Play Rock, Paper, or Scissors against the computer.
* 🤖 Random computer move generation.
* 🏆 Real-time score tracking for both the player and the computer.
* 🎨 Dynamic result messages for wins, losses, and draws.
* 🟢 Green indicator for a win.
* 🔴 Red indicator for a loss.
* 🔵 Blue indicator for a draw.
* 🖱️ Interactive hover effects for game choices.
* 📱 Responsive design for different screen sizes.
* ⚡ Simple and beginner-friendly user interface.

---

## 🛠️ Technologies Used

* **HTML5** – Provides the structure of the application.
* **CSS3** – Handles styling, layout, and responsiveness.
* **JavaScript (ES6)** – Manages game logic, random computer choices, score updates, and DOM manipulation.

## 🎯 How to Play

1. Open the game in your web browser or use the **Live Demo** link above.
2. Choose **Rock**, **Paper**, or **Scissors**.
3. The computer randomly selects its move.
4. The game compares both choices.
5. The result is displayed as:

   * ✅ **Win**
   * ❌ **Lose**
   * 🤝 **Draw**
6. Scores are automatically updated after each round.

---

## 🧠 Game Rules

The game follows the standard Rock Paper Scissors rules:

* ✊ **Rock beats Scissors**
* ✋ **Paper beats Rock**
* ✌️ **Scissors beats Paper**

The computer's choice is generated randomly using JavaScript's `Math.random()` function.
